# johnmark.dev — Portfolio

Personal portfolio site for John Mark Alojado — IT support & cybersecurity
specialist. Showcases 7 open-source security tools and the résumé.

- `index.html` — main portfolio (hero, projects, experience, awards, skills)
- `resume.html` — full résumé (print-optimized: Ctrl+P → Save as PDF)

Vanilla HTML/CSS, no frameworks, no trackers. Dark theme with print support.
